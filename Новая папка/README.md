# Анализатор журналов событий

## Бизнес-требования
Службе поддержки необходим инструмент для быстрого поиска частых ошибок и их источников в журналах нескольких компонентов системы. Приложение должно обрабатывать большие файлы без загрузки всего содержимого в память, фильтровать данные по различным критериям и формировать сводную статистику.

## Реализованный функционал
- Построчное чтение файла (потоковая обработка, без загрузки всего файла в память)
- Валидация строк с выводом номера ошибочной строки
- Фильтрация по временному интервалу (начало включительно, конец исключительно)
- Фильтрация по уровню события (TRACE, DEBUG, INFO, WARN, ERROR)
- Фильтрация по источнику события
- Подсчёт корректных и ошибочных строк
- Сводка событий по уровням и источникам
- Определение Top-N кодов ошибок (детерминированный результат)
- Экспорт отчёта в JSON и CSV
- Корректная обработка пустых и отсутствующих файлов

## Архитектура
Проект разделён на модули:
- `parser.py` — парсинг и валидация строк лога
- `filter.py` — применение фильтров (время, уровень, источник)
- `aggregator.py` — сбор и агрегация статистики
- `output.py` — форматирование и вывод результатов (терминал, JSON, CSV)
- `cli.py` — обработка аргументов командной строки
- `main.py` — точка входа, связывает все модули

## Развёртывание
Требуется WSL (Ubuntu), Python 3.8+.

```bash
pip3 install pytest pytest-cov pytest-html --break-system-packages
python3 main.py --input logs_events_sample(1).log
python3 main.py --input "logs_events_sample(1).log" --from 2026-09-01T00:00:00Z --to 2026-09-02T00:00:00Z --source auth-api --format json --output report.json
python3 main.py --input "logs_events_sample(1).log" --level ERROR --top 3 --format csv --output errors.csv
python3 main.py --input "logs_events_sample(1).log" --from 2026-09-01T00:00:00Z --to 2026-09-10T00:00:00Z --level WARN --source gateway --top 5 --format json --output gateway_warn.json
./run_tests.sh
